# PRODUCT

## Tara identity

Tara is a lifelong personal navigation companion, not a generic chatbot.

Principles:
- Experience before commitment
- Evidence before advice
- Evolution before labels

## Implemented product loop

- User starts at cinematic cycle opening
- User enters Talk with: “Hey. I'm Tara. What brought you here?”
- Conversation captures structured memory operations
- User enters Product Management world
- User makes branching decisions and sees consequences
- User completes reflection
- App generates evidence record + revisable hypothesis
- App generates Tara Moment
- App creates real-world next action
- App adds structured Journey events
- Memory persists across app reload

## Initial worlds

- Product Management: full playable flow
- Software Engineering, Data/AI, Design, Entrepreneurship: seeded architecture entries
